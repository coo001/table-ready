Table Ready: app map

One action: press Plan my dinner.

1. Input index.html + js/app.js (renderDishes, state saved to localStorage tableready.v1)
2. Planning js/app.js plan() converts clock time to minutes and calls Scheduler.plan in js/scheduler.js: order dishes (hot first), place each dish's steps from last to first, slide a step earlier when hands, burners or the oven are busy.
3. Check Scheduler.verify re-checks every rule; test/scheduler.test.js runs it.
4. Output js/app.js render() draws headline, warnings, timeline and checklist.

A practice to reuse

Write the rule as a check before the code: here, verify was written as an independent function, and it exposed the 95-minute wait that the first ordering produced.

Run: python3 -m http.server 8000, tests: node test/scheduler.test.js.
